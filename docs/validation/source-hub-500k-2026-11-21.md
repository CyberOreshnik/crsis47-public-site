## Limitations and remaining gates
- The measured percentiles are **in-process local SQLite pagination timings**, not network API latency, not concurrency percentiles, and not a free-tier hosting SLA.
- No measured production database size, peak RSS, concurrent-request throughput, or realistic multi-user load was recorded in this run.
- Cursor semantics intentionally return HTTP 409 after a collection revision changes; this is not an immutable snapshot across writes.
- Search response correctness for diverse multilingual, complex and adversarial queries requires broader tests.
- Source Hub frontend and all other collections require browser-level network assertions to establish that unrelated datasets are not downloaded.
- A hosted free-tier API has not been provisioned or verified. Do not enable billing or expose private records.
- Website visual preservation and the full approved TIMEPIECE laboratory require separate acceptance.

**Decision:** Local 500k synthetic validation gate PASS. Whole-site production scalability gate REVISE. Do not equate these statuses.
